# AutoLoc

## Présentation du projet

AutoLoc est une plateforme de gestion de location de véhicules
multi-agences.

La plateforme permet de gérer les différentes activités liées à
la location de véhicules au niveau de plusieurs agences.

## Acteurs

Les principaux acteurs identifiés sont :

- Client
- Agent d'agence
- Responsable d'agence
- Administrateur

## Objectifs

L'objectif du projet est de proposer une solution permettant de
gérer les activités de location de véhicules de manière organisée
au sein d'une plateforme multi-agences.
